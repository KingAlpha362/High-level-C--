# C++ Data Structures Practice

Standalone exercises exploring queues, stacks, linked lists, and small class-based programs.

## ✨ Highlights

- Array-backed queue operations in `array-queue.cpp`.
- Linked-list insertion, deletion, and searching in `booklibrary.cpp`.
- Additional score, song-playlist, and stack exercises.

## 🚀 Getting started

With a C++ compiler installed, compile one exercise at a time:

```sh
g++ -std=c++17 "array-queue.cpp" -o exercise
./exercise
```

On Windows PowerShell, use `-o exercise.exe` and run `.\exercise.exe`. Each exercise is separate; do not link every source file into one executable.
